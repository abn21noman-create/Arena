লাইভ টেস্ট করতে গিয়ে ধরা পড়ে — DB এর ১৮৫টা টপিকের মধ্যে মাত্র **৮২টায়**

কিন্তু এতে দুটো বাস্তব সমস্যা তৈরি হচ্ছিল:

1. **৫৭টা নোট-বিহীন টপিকে MCQ প্রশ্ন ছিল** — ছাত্র কুইজে ভুল করে "পড়া"
   ট্যাবে ব্যাখ্যা খুঁজতে গিয়ে খালি পেজ পেত।
2. **Mind-map ফিচার নোট ছাড়া কাজই করে না** — API সরাসরি ৪০০ দিত:

## যোগ করা ১০৩টা নোট (৬টি seed স্ক্রিপ্টে)

| `db:seed-hmath-notes-gaps` | ১৬ |
| `db:seed-biology-notes-gaps` | ২৮ |
| **মোট** | **১০৩** |

প্রতিটা নোটে থাকে:
- বাংলা Markdown (H1 শিরোনাম + H2 সেকশন)
- KaTeX গাণিতিক সূত্র (`$...$` ও `$$...$$`)
- আলাদা `formulaSheet` — দ্রুত রিভিশনের জন্য
- গড় দৈর্ঘ্য ~২,২০০ অক্ষর

সব seed **idempotent** — H1 শিরোনাম মিলিয়ে নিজের কনটেন্ট চেনে, তাই
কোনো টাইপো ঠিক করে আবার চালালেই DB আপডেট হয়, কিন্তু অন্য seed এর
কনটেন্ট কখনো ওভাররাইট হয় না।

## মান যাচাই: `pnpm verify:notes`

নোট শুধু "আছে" হলেই যথেষ্ট নয় — ভাঙা KaTeX ছাত্রের পেজে লাল render
error দেখাবে। তাই `scripts/verify-notes-quality.ts` প্রতিটা নোট যাচাই করে:

1. প্রতিটা math এক্সপ্রেশন **আসল KaTeX পার্সার** দিয়ে রেন্ডার করে দেখা
2. `$` ও `$$` ডিলিমিটার জোড়ায় আছে কিনা
3. math mode এ `\text{}` ছাড়া বাংলা অক্ষর আছে কিনা
4. markdown হেডিং দিয়ে শুরু, যথেষ্ট দৈর্ঘ্য
5. বাংলা কনটেন্ট আছে (English সাবজেক্ট বাদে)
6. একই নোট একাধিক টপিকে কপি-পেস্ট হয়েছে কিনা
7. সাবজেক্টভিত্তিক কভারেজ রিপোর্ট

## ধরা পড়া ও ঠিক করা বাগ

এই কাজ করতে গিয়ে নিজের তৈরি করা ৫টা সমস্যা ধরা পড়েছে — স্বচ্ছতার
জন্য লিখে রাখা:

| সমস্যা | কারণ ও সমাধান |
|---|---|
| চেকারে ৮টা false positive | হাতে-লেখা regex `\sqrt2` ও `\frac12` কে "আর্গুমেন্ট নেই" বলছিল, অথচ KaTeX এ ব্রেসবিহীন single-token বৈধ। সমাধান: regex বাদ দিয়ে **আসল KaTeX পার্সার** ব্যবহার |
| English নোটে "বাংলা কম" ৩টা false positive | English সাবজেক্টের নোট ইংরেজিতেই থাকা স্বাভাবিক। সমাধান: `code === "ENGLISH"` হলে শর্ত শিথিল |
| `esbuild: Unexpected "}"` | KaTeX এর `${}^1\mu_2$` কে JS template interpolation ধরছিল। সমাধান: `\$` দিয়ে escape |
| KaTeX ফিক্স DB তে পৌঁছাচ্ছিল না | seed এর গার্ড পুরো টেক্সট তুলনা করত, তাই টাইপো ঠিক করলেই "অন্য seed এর নোট" ভেবে skip করত। সমাধান: শুধু **প্রথম লাইন (H1)** মিলিয়ে নিজের কনটেন্ট চেনা |
| math mode এ বাংলা | `E°_{ক্যাথোড}` KaTeX warning দিচ্ছিল। সমাধান: `\text{}` এ মোড়া, এবং চেকারে এই যাচাই স্থায়ীভাবে যোগ |

চতুর্থটি বিশেষভাবে ছলনাময় ছিল — স্ক্রিপ্ট "সফল" রিপোর্ট করছিল, অথচ
আসল ফিক্সটা কখনো DB তে যাচ্ছিল না।
