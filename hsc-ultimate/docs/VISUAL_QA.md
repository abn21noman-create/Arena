## এতদিন কেন হয়নি

তিনটি সেশনে "চাক্ষুষ QA বাকি" লেখা ছিল — কারণ এই স্যান্ডবক্সে কোনো
ব্রাউজার নেই, root নেই, RAM ২ GB। থিম যাচাই হচ্ছিল শুধু HTML/CSS
**পড়ে**, আসলে কেমন দেখায় তা কেউ দেখেনি।

এবার সেটা সমাধান করা হলো, root ছাড়াই:

| বাধা | সমাধান |
|---|---|
| ব্রাউজার নেই | `pip install playwright` + `playwright install chromium` |
| ৯টা সিস্টেম লাইব্রেরি অনুপস্থিত (`libnspr4`, `libnss3`, `libatk`, `libasound`...) | `apt-get download` (root লাগে না) → `dpkg-deb -x` → `~/libs/root` → `LD_LIBRARY_PATH` |
| বাংলা গ্লিফ ▯▯▯ | `fonts-beng-extra` + `fonts-lohit-beng-bengali` একইভাবে → `~/.local/share/fonts` |
| ইমোজি ▯ | `fonts-noto-color-emoji` |
| "Unable to capture screenshot" | `--disable-features=CDPScreenshotNewSurface` ফ্ল্যাগ |
| dev কম্পাইল + Chromium একসাথে OOM | ব্রাউজার খোলার **আগে** HTTP দিয়ে পেজ warm করা |

প্রতি নতুন সেশনে চালানোর আগে:

```bash
export LD_LIBRARY_PATH=/home/user/libs/root/usr/lib/x86_64-linux-gnu:$LD_LIBRARY_PATH
```

### 🔴 বাগ ১ — League কার্ডে WCAG কনট্রাস্ট ফেল

Dashboard ও Leaderboard এ league কার্ডের ব্যাকগ্রাউন্ড টিয়ারের নিজস্ব
রঙ থেকে তৈরি হয়, কিন্তু টেক্সট রং হার্ডকোড `text-white` ছিল।
কনট্রাস্ট মেপে দেখা গেল **৫টার মধ্যে ৪টা টিয়ারে সাদা টেক্সট ফেল**:

| টিয়ার | রং | সাদা টেক্সট | রায় |
|---|---|---|---|
| BRONZE | `#cd7f32` | 3.14:1 | ⚠️ |
| SILVER | `#c0c0c0` | 1.82:1 | ❌ |
| **GOLD** | `#ffd700` | **1.40:1** | ❌ প্রায় অদৃশ্য |
| PLATINUM | `#67e8f9` | 1.45:1 | ❌ |
| DIAMOND | `#a78bfa` | 2.72:1 | ❌ |

**প্রভাব**: ছাত্র ব্রোঞ্জ থেকে উপরে উঠলেই লেখা পড়া কঠিন হয়ে যেত —
গেমিফিকেশনের পুরস্কারই কার্যত শাস্তি হয়ে দাঁড়াত।

**ফিক্স**: `lib/league.ts` এ প্রতিটি টিয়ারে কনট্রাস্ট-নিরাপদ `textHex`
যোগ; দুই পেজ থেকে হার্ডকোড `text-white` সরানো। নতুন কনট্রাস্ট
**৫.৫৬ – ১২.৪৭:১**, সবই AA পাস।

**রিগ্রেশন গার্ড**: `pnpm test:logic` এ ৮টা নতুন assertion যোগ (১৫৪ → ১৬২)।
টেস্টটি vacuous নয় — এটি নিজে যাচাই করে যে পুরনো বাগটা (GOLD এ সাদা)
সত্যিই ধরা পড়ে।

### 🟠 বাগ ২ — নেভিগেশন ও পেজ শিরোনাম ইংরেজিতে

পুরো অ্যাপ বাংলা-ভাষী শিক্ষার্থীর জন্য — বর্ণনা, বাটন, কার্ড, সেকশন
হেডিং সব বাংলায়। অথচ:

- সাইডবারের **২১টা নেভ আইটেমের ১৯টা** ইংরেজিতে
- পেজের হিরো **`<h1>` শিরোনামের ২০টা** ইংরেজিতে

একই ফাইলে `desc` ফিল্ড বাংলায়, আর ২টা নেভ আইটেম ("মিস্টেক ভল্ট",
"ফর্মুলা খুঁজুন") আগেই বাংলায় — অর্থাৎ বাংলাই উদ্দেশ্য ছিল, অনুবাদ
অসম্পূর্ণ থেকে গিয়েছিল।

**ফিক্স**: `lib/nav-modules.ts` এর ১৯টা `title` + `more-menu-sheet.tsx`
এর "Admin Panel" + ২০টা পেজ `<h1>` — সব বাংলায়। সাইডবার ও পেজ
শিরোনাম এখন হুবহু মেলে।

প্রচলিত ইংরেজি সংক্ষেপ (MCQ, CQ, PDF, AI, XP) অপরিবর্তিত — বাংলাতেও
এগুলো এভাবেই বলা হয়।

### 🟠 বাগ ৩ — শেষ কার্ড bottom-nav এর গায়ে লেগে থাকত

`BottomNavBar` এ একটি spacer আছে যাতে কনটেন্ট nav-এর পিছনে ঢাকা না
পড়ে। কিন্তু spacer এর উচ্চতা ছিল **ঠিক nav-এর সমান** (`3.5rem`)।
ফলে কনটেন্ট ঢাকা পড়ত না ঠিকই, কিন্তু পেজের শেষ কার্ডটা nav-এর গায়ে
একদম **লেগে থাকত** — মাপা গ্যাপ ছিল **−1px**।

দেখতে দমবন্ধ লাগত, আর শেষ কার্ডে ট্যাপ করতে গিয়ে ভুলে nav ট্যাপ
হওয়ার ঝুঁকি ছিল।

**ফিক্স**: spacer এ ১rem শ্বাস-জায়গা যোগ —
`calc(3.5rem + 1rem + env(safe-area-inset-bottom))`।
গ্যাপ এখন **+15px**। spacer গ্লোবাল layout-এ থাকায় ফিক্সটা **সব
পেজেই** কাজ করে।

আগের সেশনে নেভিগেশনে "AI প্রশ্নোত্তর" করা হয়েছিল, কিন্তু ল্যান্ডিং
পেজের বাটন, ai-tutor পেজের শিরোনাম ও learn পেজের ফলব্যাক বার্তায়

(SEO metadata ও admin panel ইংরেজিই রাখা হয়েছে — যথাযথ)।

### নতুন রিগ্রেশন টেস্ট: `pnpm test:mobile`

`scripts/test-mobile-layout.py` আসল Chromium এ ৩৯০×৮৪৪ খুলে যান্ত্রিকভাবে মাপে:

1. **মোবাইল emulation প্রয়োগ হয়েছে কিনা** (স্যানিটি গার্ড)
2. অনুভূমিক ওভারফ্লো নেই
3. ভিউপোর্ট ছাড়ানো এলিমেন্ট নেই
4. bottom-nav রেন্ডার হয়েছে
5. nav-এ কনটেন্ট ঢাকা পড়ে না
6. nav-এর উপরে ≥8px শ্বাস-জায়গা
7. ট্যাপ-টার্গেট ≥24px (WCAG 2.5.8)

ফল: **২১/২১ পাস** (`/dashboard`, `/practice`, `/learn`)

চেকারটি **vacuous নয়** — থ্রেশহোল্ড কৃত্রিমভাবে ৯৯৯px করে যাচাই করা
হয়েছে যে সত্যিই ফেল করে।

## সীমাবদ্ধতা

- RAM ২ GB — একসাথে অনেক পেজ নেওয়া যায় না; ভারী পেজে dev server
  মাঝেমধ্যে OOM এ পড়ে (স্ক্রিপ্ট নিজে রিস্টার্ট করে)

  অ্যাপ নিজে Anek Bangla self-host করে বলে আসল রেন্ডার ঠিক
- `/analytics` ও `/settings` ব্রাউজার দিয়ে মাপা যায়নি — dev কম্পাইল +
  Chromium একসাথে চললে কার্নেল OOM (dmesg এ প্রমাণিত:
  `Out of memory: Killed process ... next-server ... anon-rss:1210748kB`)।
  **পেজ দুটির নিজস্ব সমস্যা নেই** — HTTP দিয়ে যাচাই করা হয়েছে,
  `/settings` ৪ সেকেন্ডে 200 OK (৮৮ KB)। বেশি RAM এর পরিবেশে
  `ALL=1 pnpm test:mobile` দিয়ে চালানো যাবে।
