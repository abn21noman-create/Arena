## নতুন গ্যাপ কীভাবে ধরা পড়ল

আগের অডিটগুলো MCQ গ্যাপ মেপেছিল **চ্যাপ্টার লেভেলে** — "প্রতি চ্যাপ্টারে
অন্তত ৬টা প্রশ্ন আছে কিনা"। সেই মানদণ্ডে সব ঠিক দেখাচ্ছিল।

কিন্তু **টপিক লেভেলে** মাপতেই বেরিয়ে এল:

```
১৮৫টা টপিকের মধ্যে ৪৬টায় একটিও MCQ নেই
```

আর এই ৪৬টা ঠিক সেই টপিক, যেগুলোতে আগের সেশনে নোট লেখা হয়েছিল —
অর্থাৎ ছাত্র পড়তে পারত, কিন্তু কখনো প্র্যাকটিস করতে পারত না।

`"unpracticed_important"` সাজেশন — দুটোই

প্রশ্ন না থাকলে টপিকটা কখনো সাজেশনে আসত না।

### ৩. weak-topic রিপোর্টে অদৃশ্য
Analytics এ দুর্বলতা মাপা হয় উত্তরের ভিত্তিতে; প্রশ্নই না থাকলে ছাত্র
ঐ টপিকে দুর্বল কিনা তা কখনো জানা যেত না।

## মান যাচাই: `npm run verify:questions`

নতুন চেকার `scripts/verify-question-quality.ts` — ৯ শ্রেণির যাচাই:

1. 🔴 **`correctAnswer` অবশ্যই `options` এর একটি হতে হবে**
2. অপশন সংখ্যা ঠিক ৪টা
3. ডুপ্লিকেট অপশন নেই
4. খালি text/option নেই
5. একই টপিকে হুবহু একই প্রশ্ন দুইবার নেই
6. ব্যাখ্যা আছে ও যথেষ্ট দীর্ঘ
7. প্রশ্নের text যথেষ্ট দীর্ঘ
8. প্রতিটা টপিকে অন্তত ১টা প্রশ্ন
9. সাবজেক্টভিত্তিক কভারেজ + difficulty রিপোর্ট

**১ নম্বর চেকটা কেন সবচেয়ে গুরুত্বপূর্ণ**: `practice/submit` এ স্কোরিং
হয় `question.correctAnswer === a.userAnswer` স্ট্রিং তুলনায়। যদি
`correctAnswer` অপশনের মধ্যে না থাকে, ছাত্র **যা-ই উত্তর দিক সবসময় ভুল
হবে** — এবং কোনো error দেখাবে না, নীরবে accuracy নষ্ট করবে।

## ধরা পড়া ও ঠিক করা বাগ

### 🐛 বাগ ১ — টপিকের নাম ইংরেজিতে লেখা ছিল

বাংলা ১ম পত্রের একটি টপিকের `name` ফিল্ডে বাংলা নামের বদলে ইংরেজি
transliteration বসানো ছিল:

```ts
// prisma/seed.ts:755 (আগে)
{ name: "aparichita", nameEn: "Aparichita", isImportant: true }
```

বাকি সব টপিকে যেখানে `{ name: "সোনার তরী", nameEn: "Sonar Tori" }`।

**প্রভাব (নিছক কসমেটিক নয়)**:
- পুরো অ্যাপ বাংলা-ভাষী শিক্ষার্থীর জন্য, অথচ "পড়া" তালিকায়, bookmark এ,
  weak-topic রিপোর্টে ও PDF নোটের শিরোনামে ছোট হাতের `aparichita` দেখাত
- ঐ টপিকের নোটের H1 কিন্তু ঠিকই `# অপরিচিতা` — অর্থাৎ পেজের শিরোনাম ও
  নোটের শিরোনাম দুই রকম
- বাংলায় "অপরিচিতা" লিখে সার্চ করলে টপিকটা পাওয়া যেত না

**ফিক্স**: `db:fix-topic-name-aparichita` (DB) + `seed.ts` ও দুটি
নির্ভরশীল seed ফাইলের কী (`seed-bangla-notes.ts`,
`seed-bangla-english-ict.ts`) — যাতে re-seed করলে বাগটা ফিরে না আসে।

> ⚠️ শেষ অংশটা গুরুত্বপূর্ণ ছিল: শুধু `seed.ts` ঠিক করলে ঐ দুটি seed
> `findFirst({ where: { name: "aparichita" } })` দিয়ে খুঁজে আর পেত না,
> ফলে ভবিষ্যতে নীরবে skip করত।
